Revision: 35b116d5eb059d552fa46fac3ce2963ed13ce153

pylocalvqe modified the upstream build to link LocalVQE and ggml statically
inside a shared core, limit exported symbols, disable dynamic ggml backend
file loading, and expose the upstream SHA-256 implementation internally.
The upstream fused-GRU patch is applied to the pinned ggml source.
The ordered patches and complete source manifest are in cpp/cmake/ and
scripts/cmake/. pylocalvqe's own core and Python interface wrap this build.
